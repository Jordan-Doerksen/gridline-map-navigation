# Gridline — Map Navigation Foundations

Gridline is a browser-based beginner course for topographic map reading and introductory land navigation. It combines short lessons with interactive grid, scale, contour, bearing, route-planning, and self-assessment exercises.

## Course modules

1. Read the whole map sheet
2. Grid references and precision
3. Scale and distance
4. Contours and landforms
5. Grid, true, and magnetic north
6. Bearings and route construction
7. Safe field rehearsal
8. Foundation self-check

The illustrated maps, coordinates, profiles, and route metrics are synthetic training examples. Factual guidance is grounded in the Natural Resources Canada references linked from the course.

## Run locally

Requires Node.js 22.13 or newer.

```sh
npm ci
npm run dev
```

Then open the local address printed by the development server. For a production build:

```sh
npm run build
```

## Training boundary

This project teaches foundational concepts. It does not replace current authoritative maps, appropriate outdoor safety planning and equipment, local permissions, or qualified navigation instruction.
